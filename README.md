# Objetivo do Projeto
 
O principal objetivo do Soul Mind é aumentar o engajamento das pessoas com a sustentabilidade através da gamificação, tornando pequenas ações ambientais mais acessíveis, motivadoras e recompensadoras.
 
---
 
# Tecnologias Utilizadas
 
As seguintes tecnologias foram utilizadas no desenvolvimento do projeto:
 
- HTML
- CSS
- JavaScript
- Figma
- GitHub
- Visual Studio Code
